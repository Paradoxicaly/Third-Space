## Visual and assistive-technology matrix (§4.7)

- [ ] iPhone smallest supported simulator, standard and large phone, iPad portrait/landscape, compact Split View: light/dark/system choice; safe areas, keyboard, rotation, sheet detents and map/legal attribution remain visible. Local native iPad shell is implemented and simulator-tested; actual Split View/Stage Manager, smallest/physical/minimum-OS devices and future map attribution remain unverified.
- [ ] Native **actual composited** normal text ≥4.5:1, essential icons/borders ≥3:1 in light/dark, selected/focused/disabled/loading/error and map/photo overlays; static JSON pair verifier compares unrounded sRGB values but cannot test blur, opacity, rendering or screenshots.
- [ ] Default through largest accessibility Dynamic Type: place/local names, original script, title, practical restrictions, provenance, credit, form validation, buttons and status not clipped; expanded sheet reachable without dragging. ≥44×44 pt hit targets, sufficient separation; document observed failures.
- [ ] VoiceOver order: search → filters → area actions → results/selected card → tabs; “Show results as list” prominent. Pin says name/type/precision, not raw coordinates; cluster announces count and zoom action; avoids hundreds of unavoidable annotations; focus restores after dismissal. Test all Add steps, errors, reports, deletion and one-level question replies.
- [ ] Switch Control, iPad hardware keyboard, Voice Control labelled controls and non-drag alternatives; selected/deselected state and submission feedback spoken and visually explicit.
- [ ] Reduce Motion: no camera flight/pulse/spring; Reduce Transparency: opaque readable planes; Increased Contrast, grayscale and color-vision simulations: status is icon + word, selection is outline/check + word.
- [ ] Long Arabic RTL, CJK, mixed original/translation, 30% expansion, localized currency/date/zone and local units; map compass/location controls not blindly mirrored. Test original text always accessible when translation fails.
- [ ] No photo, slow/rejected/portrait/removed media, long credit and alt text; no invented placeholder photograph or cropped access detail. Metadata GPS removed and sensitive background clues reviewed in actual pipeline (not proven by UI).

## Journey and degraded-state checks

- [ ] World/region/manual city selection before any location permission; no default Carson/nearby claim. Search own places separately from ephemeral Apple cities/areas; approve-only markers/rows; cluster zoom and overlapping member list; antimeridian/rural cases, deliberate Search this area, common map/list filters/cursor/area/selection restoration. Map cap is not mistaken for total; offline/cached content labelled as-of date.
- [ ] Denied/restricted/reduced location retains manual browse; map tiles unavailable retains owned list; Apple area search failure retains owned region/places; backend outage with cache and cold offline empty state are distinct from zero approved coverage and zero filter matches. Auth expiration preserves draft and guest browse. Backend/provider failures do not insert fake results.
- [ ] Place practical facts show unknown, provenance/freshness, precision and safe directions; no evergreen Open now without checked local hours/exception. Contribute duplicate/position/text alternative/rights/privacy preview/pending receipt; interrupted upload/retry does not double-post or lose draft. Questions, corrections, report/block, collections, event cancellation and Featured expiry have separate real-state checks.
- [ ] Region/language operations pause remote submissions without preventing worldwide browsing/local drafts. Sensitive exact geometry and derived post/photo/translation/source/collection/map representations cannot leak; approved/current-revision predicates apply to every public surface and count. Staff grant revocation, self-approval denial and sensitive second reviewer exercised against server, not just hidden controls.
- [ ] Owner/community takedown contact without account, UGC reporting/blocking, reauthenticated export/deletion and honest purge-progress receipt actually function on staging. Disconnected caches cannot be promised immediate erasure. Actual provider display/rights, regional coverage, age policy, staffing, retention/backup, cost and distribution gates remain independent.

## Release gate (future)

Do not mark release ready until native target/scheme and nonzero unit/UI suites pass with actual result bundles; §4.7 assistive-tech and responsive matrix is documented; physical-device provider/attribution tests are separate from deterministic mocks; RLS/storage and sensitive-location adversarial tests pass; source rights and regional reviewers are signed off; real approved seeds replace clearly labelled synthetic fixtures; account/privacy/support/rights flows and archive/TestFlight signing are verified by authorized owners. Record blockers explicitly. A successful script or unsigned simulator build alone satisfies none of these release approvals.
